# Security and privacy reports

For a suspected vulnerability or a report containing private information, contact **siveesh@learnwithsk.com** instead of opening a public issue. Include the affected version, reproduction steps and likely impact. Do not send credentials, private keys, complete personal catalogs or unrelated files.

Ordinary bugs can be reported through [GitHub Issues](https://github.com/siveesh/sks-app-menu/issues). There is no guaranteed response or support SLA. Maintainers will investigate actionable reports and coordinate a fix when appropriate.

The app uses local preferences and reads application metadata. It does not modify installed apps, bypass macOS launch checks, or send catalog data to a service. Public release notes state the actual signing/notarization status. Developer ID signing alone is not notarization; do not disable Gatekeeper or strip quarantine to work around an unnotarized release.
