# Release Checklist

- [ ] Release scope and version approved.
- [ ] Build and tests have recorded evidence.
- [ ] Privacy, storage, and data-recovery behavior reviewed.
- [ ] License and third-party notices reviewed.
- [ ] Packaging, signing, notarization, and distribution plan documented where applicable.
- [ ] Release notes and user-facing help updated.
- [ ] Final artifact location and retention policy recorded.
